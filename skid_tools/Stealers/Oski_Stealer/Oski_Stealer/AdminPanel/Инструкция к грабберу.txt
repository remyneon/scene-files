Rule name - имя правила для грабера
Указывается на латинице, без спец. символов

Path to start - стартовый патч для грабера, с которого тот начнет искать файлы
Есть возможность выбрать готовые варианты:
UserProfile - начнет поиск с папки C:\Users\username, где username - имя активного пользователя
Desktop - начнет поиск с рабочего стола активного пользователя
Documents - начнет поиск с папки "Мои документы" активного пользователя
AppData - начнет поиск с папки C:\Users\username\AppData\Roaming активного пользователя
LocalAppData - начнет поиск с папки C:\Users\username\AppData\Local активного пользователя

File masks - список масок для поиска файлов
Формат масок - windows wildcards
https://ss64.com/nt/syntax-wildcards.html

Допустимые маски, примеры: 
*.txt - найдет все файлы .txt
2fa.* - найдет все файлы с названием 2fa.
*2fa*.txt - найдет все файлы с упоминанием 2fa в названии файла, формат .txt
*2fa*.*txt* - найдет все файлы с упоминанием 2fa в названии файла, с упоминанием txt в формате файла

Форматы и упоминания могут быть любыми на ваш вкус
